Was ein Verein hat, kann der nächste leihen.

Festzelt, Bierzeltgarnituren, PA-Anlage, Hüpfburg: Jeder Verein besitzt Dinge, die er nur dreimal im Jahr braucht. Vereinsverleih macht das Inventar sichtbar – und das Ausleihen so einfach wie eine Online-Bestellung.

Auf GitHub herunterladen Wie es funktioniert

Das Problem

Vereine kaufen oder mieten teuer, was im Nachbarverein im Keller steht. Anfragen laufen über WhatsApp, Zettel und Zufall – niemand weiß, wer wann was hat.

Doppelt gekauft

Dasselbe Zelt steht in fünf Vereinsheimen und wird je Verein nur ein paar Tage im Jahr genutzt.

Unübersichtlich

Wer hat was und wann frei? Absprachen per Telefon und Chat gehen verloren.

Unklare Regeln

Manches verleiht man gern an Vereine, aber nicht an Privatleute – oder gar nicht. Diese Regeln stehen nirgends.

So funktioniert's

Drei Schritte vom Eintragen bis zur Rückgabe.

1

Inventar eintragen

Verein registrieren, Gegenstände mit Foto, Bestand, Kaution und Abholort anlegen. Mitglieder per E-Mail einladen.

2

Im Katalog finden

Der öffentliche Katalog zeigt alles Verleihbare mit Suche und Filtern. Belegte Zeiträume sind direkt sichtbar.

3

Anfragen & verleihen

Anfrage mit Zeitraum und Menge senden. Der Verein genehmigt oder lehnt ab – beide Seiten werden per E-Mail informiert.

Angefragt→Genehmigt→Ausgeliehen→Zurück

Pro Gegenstand: Wer darf leihen?

Jeder Verein entscheidet selbst – für jedes einzelne Teil.

⚑

Nur andere Vereine

Anfragen nur von angemeldeten Vereinen, z. B. für die große PA-Anlage.

☺

Nur Privatpersonen

Z. B. die Hüpfburg für den Kindergeburtstag – ganz ohne Konto per E-Mail-Bestätigung.

⚑☺

Vereine und Privatpersonen

Der Klassiker: Bierzeltgarnituren und Pavillons für alle.

⌂

Niemand / nur intern

Bleibt im Bestand erfasst, erscheint aber nicht im Katalog.

Was drinsteckt

Ein sauber strukturierter MVP, gebaut zum Erweitern.

  • Vereinsverwaltung mit Rollen Admin / Mitglied
  • Bestandsprüfung je Zeitraum und Verfügbarkeitskalender – keine Überbuchung
  • Rückgabe-Erinnerung, Mahnung und Verlängerungsanfragen
  • Wiederholungs-Ausleihen: z. B. jeden Samstag im Sommer, in einem Rutsch geprüft und genehmigt
  • Warteliste: Bescheid per E-Mail, sobald ein belegter Gegenstand frei wird
  • CSV-Export der Ausleihen für Excel & Co.
  • Privatpersonen ohne Konto, mit Bestätigungs-Link
  • E-Mail-Benachrichtigungen über eine Queue
  • Fotos, Kategorien, Kaution, Abholort
  • Spam-Schutz: Honeypot, Rate-Limit, E-Mail-Verifizierung
  • Komplett deutsch, mobil nutzbar, Dark Mode
  • Läuft auf normalem PHP-Webhosting – kein Node, kein Server-Root

Selbst betreiben

Jeder Verband oder Stadtteil kann eine eigene Instanz hosten. Voraussetzungen: PHP 8.3+, MySQL/MariaDB, ein Cronjob.

Laravel 13PHP 8.3+MySQL 8Inertia.jsVue 3TypeScriptTailwind CSSDocker (lokal)
git clone https://github.com/fotonaut/vereinsverleih.git
cd vereinsverleih
cp .env.example .env
docker compose up -d mysql mailpit
docker compose run --rm app composer install
docker compose run --rm app php artisan key:generate
docker compose run --rm app php artisan migrate --seed
